# Product

This is a static study guide website for the **AWS DOP-C02 DevOps Engineer Professional** certification exam.

## Purpose

Synthesizes 360 exam-style questions (Q1–Q392) into domain-focused deep-dive reference pages. It is a personal/educational tool, not a commercial product.

## Content Structure

Six exam domains are each covered in a dedicated doc file:

1. SDLC Automation (22% exam weight)
2. Configuration Management and IaC (17%)
3. Resilient Cloud Solutions (15%)
4. Monitoring and Logging (15%)
5. Incident and Event Response (14%)
6. Security and Compliance (17%)

A cross-reference index (`99-question-cross-reference.md`) maps every question number to its domain section.

## Content Conventions

- ASCII only — no smart quotes (`"`/`"`), em dashes (`—`), or ellipsis (`…`) characters
- Question citations inline: `(Q1, Q47, Q142)`
- AWS documentation URLs preserved verbatim from source explanations
- Each domain file uses three Docusaurus admonition types:
  - `:::tip` — Learning Objectives block at the top of each section
  - `:::warning` — Exam Tip for must-know gotchas
  - `:::note` — Key Takeaway to close major sections
- Decision tables use plain Markdown pipe tables
